   файлами из этого архива. Файлы размещаются рядом, в корне сайта.
7. Обновите страницу сайта (Ctrl+F5), под кнопкой оплаты появится
   «Я разработчик». Введите тот же ID, последние 4 цифры и телефон.
8. При совпадении скачайте сертификат MyEngine-Deluxe-….json.

Начальные developerAccess.enabled=false и пустой хеш намеренны:
ваши 4 цифры карты, телефон и ID разработчика не предоставлены.
Мастер заполнит эти настройки локально. Ничего присылать в чат не требуется.
Формат телефона может содержать пробелы, скобки и дефисы; российские
8XXXXXXXXXX и +7XXXXXXXXXX приводятся к одному виду. Другие номера
вводите с кодом страны. ID проверяется с учётом регистра.
Папку tools не нужно публиковать. Для перенастройки сохраните её локально;
мастер использует config.js из папки уровнем выше и сохраняет остальные поля.
Для отключения режима установите developerAccess.enabled=false.

ЧТО ОЗНАЧАЕТ ЭТА ПРОВЕРКА
Это согласованная простая браузерная сверка. Банк, ЮMoney и SMS в ней
не участвуют; владение картой или телефоном она не подтверждает.
В config.js сохраняется SHA-256 от сочетания данных с публичной солью.
Исходные 4 цифры и телефон туда не записываются, но хеш не защищает
от перебора и изменения JavaScript посетителем. Сертификат без подписи
тоже можно изменить. Не считайте его доказательством банковского платежа.
На стороне сайта эти данные не отправляются по сети и не записываются
в localStorage/sessionStorage, сертификат или платёжную форму ЮMoney.
После успешного создания поля карты и телефона очищаются.

СЕРТИФИКАТ РАЗРАБОТЧИКА
Формат: JSON, schema=myengine-license/v1.
product=MyEngine, edition=Deluxe, grantType=developer, licenseStatus=issued.
playerId привязан к ID, заданному владельцем в локальном мастере.
payment.status=not_required, payment.amount=0, payment.currency=RUB.
verification.method=local_configuration_match.
bankVerified=false, serverVerified=false, signature=null.
Это бесплатная лицензия разработчика. Банковской операции не было.
Телефон, 4 цифры, хеш и соль в сертификат не включаются.
В MyEngine пока нет добавленного этим архивом загрузчика сертификатов:
нужна отдельная интеграция с исходниками приложения. Сам JSON не меняет
файлы, баланс или права существующей установки MyEngine.

КАК РАБОТАЕТ ОПЛАТА
Форма отправляется POST на https://yoomoney.ru/quickpay/confirm.
Обязательные поля: receiver, quickpay-form=button, paymentType=PC/AC,
sum=10.00. label содержит ID и уникальный суффикс, длина не более 64.
successURL возвращает посетителя на страницу с payment=returned.
Данные карты вводятся исключительно на стороне ЮMoney.
Сумма sum — списание с отправителя. Зачисление получателю может быть меньше
из-за комиссии; актуальную комиссию смотрите у ЮMoney.
ID разрешён длиной 1–32: латинские буквы, цифры, точка, подчёркивание, дефис.
Пользовательский ID уходит ЮMoney в составе метки. Параметры формы не секретны.
Незавершённая метка хранится только в sessionStorage вкладки для показа при
возвращении. Если оно заблокировано, форма работает без сохранения метки.

АКТИВАЦИЯ
Этот архив НЕ изменяет баланс и НЕ активирует Deluxe в MyEngine автоматически.
При обычной покупке разработчик проверяет поступление в своём кошельке
и активирует покупку вручную. Режим разработчика создаёт отдельный бесплатный
сертификат без операции ЮMoney; его схема описана выше.
Интеграция с конкретной системой аккаунтов/лицензий MyEngine не выполнена:
её API и правила выдачи не предоставлены.
Любые параметры браузера, label и ID можно подменить. Они лишь помогают
найти перевод и сами по себе не подтверждают оплату или владение аккаунтом.

ДЛЯ АВТОМАТИЧЕСКОЙ ВЫДАЧИ ПОЗЖЕ
Нужен сервер с авторизацией игрока, созданием заказа, базой и обработчиком
HTTP-уведомлений ЮMoney. Сервер выдаёт Deluxe только после проверки подписи,
суммы, валюты, состояния перевода, заказа и его привязки к аккаунту.
Секрет уведомлений хранится только на сервере. Повторная доставка одного
operation_id не должна выдавать Deluxe повторно. Сопоставляйте фактически
подписанные поля с заказом; не доверяйте неподписанным клиентским значениям.
По документации, проверенной 15.10.2026, используется sign (HMAC-SHA256),
а sha1_hash устарел. Возврат по successURL не является подтверждением.
Серверный обработчик и интеграция с MyEngine в этот статический архив не входят.
