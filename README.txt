MYENGINE DELUXE — 10 ₽
Статический сайт с формой перевода через ЮMoney

ЧТО ГОТОВО
Адаптивная страница, цена 10 ₽, ID игрока, выбор кошелька/карты,
метка перевода и инструкция после возвращения с ЮMoney.
Нет сборки, npm, внешних шрифтов, аналитики или библиотек.
Откройте index.html для просмотра. Форма включается только на HTTPS.
Приём платежей изначально отключён. Фактический перевод не тестировался.

НАСТРОЙКА
1. Откройте config.js в текстовом редакторе.
2. receiver: укажите номер своего кошелька ЮMoney внутри кавычек.
   Номер публичный. Пароли, токены и секрет уведомлений НЕ добавляйте.
3. supportUrl: укажите рабочий адрес поддержки, например HTTPS-ссылку
   на Telegram или mailto:ваш-адрес. Без контакта оплата не включится.
4. activationText: укажите реальные условия, способ и срок выдачи Deluxe.
   Сейчас выбран ручной вариант. При изменении процесса обновите также FAQ.
   Добавьте реальные возможности Deluxe в текст страницы, если нужно.
5. Только после этого установите paymentsEnabled: true.
6. Загрузите index.html, config.js, app.js, styles.css и favicon.svg
   в одну папку веб-сервера с HTTPS. Все пути относительные:
   сайт работает и в корне домена, и в /myengine-deluxe/.

GITHUB И ХОСТИНГ
Исходники можно хранить в репозитории GitHub.
Создайте репозиторий myengine-deluxe и загрузите содержимое этой папки
через Add file → Upload files. Загружайте распакованные файлы, не ZIP.

У GitHub Pages есть ограничение: сервис нельзя использовать для сайта,
основная цель которого — коммерческие транзакции. Кнопки пожертвований
и краудфандинг допускаются, но обязательная оплата за Deluxe не становится
пожертвованием от переименования. Для действующей продажи используйте
подходящий HTTPS-хостинг; GitHub может оставаться хранилищем исходников.
Автоматическая публикация магазина на GitHub Pages в архив не добавлена.

ПРОВЕРКА ПЕРЕД ЗАПУСКОМ
— Проверьте контакт поддержки, условия и правильность кошелька.
— Откройте опубликованную HTTPS-страницу, укажите тестовый ID и подтвердите условия.
— Нажмите «Оплатить 10 ₽», проверьте на ЮMoney получателя и сумму.
— Если намерены провести реальный тест, выполните один перевод сами.
— Сопоставьте его с историей кошелька; лишь затем активируйте Deluxe.
  Ни переход на сайт, ни скриншот от покупателя не доказывают поступление.

КАК РАБОТАЕТ ОПЛАТА
Форма отправляется POST на https://yoomoney.ru/quickpay/confirm.
Обязательные поля: receiver, quickpay-form=button, paymentType=PC/AC,
sum=10.00. label содержит ID и уникальный суффикс, длина не более 64.
successURL возвращает посетителя на страницу с payment=returned.
Данные карты вводятся исключительно на стороне ЮMoney.
Сумма sum — списание с отправителя. Зачисление получателю может быть меньше
из-за комиссии; актуальную комиссию смотрите у ЮMoney.
ID разрешён длиной 1–32: латинские буквы, цифры, точка, подчёркивание, дефис.
Пользовательский ID уходит ЮMoney в составе метки. Параметры формы не секретны.
Незавершённая метка хранится только в sessionStorage вкладки для показа при
возвращении. Если оно заблокировано, форма работает без сохранения метки.

АКТИВАЦИЯ
Этот архив НЕ изменяет баланс и НЕ выдаёт Deluxe в MyEngine автоматически.
Разработчик проверяет поступление в своём кошельке и активирует покупку вручную.
Интеграция с конкретной системой аккаунтов/лицензий MyEngine не выполнена:
её API и правила выдачи не предоставлены.
Любые параметры браузера, label и ID можно подменить. Они лишь помогают
найти перевод и сами по себе не подтверждают оплату или владение аккаунтом.

ДЛЯ АВТОМАТИЧЕСКОЙ ВЫДАЧИ ПОЗЖЕ
Нужен сервер с авторизацией игрока, созданием заказа, базой и обработчиком
HTTP-уведомлений ЮMoney. Сервер выдаёт Deluxe только после проверки подписи,
суммы, валюты, состояния перевода, заказа и его привязки к аккаунту.
Секрет уведомлений хранится только на сервере. Повторная доставка одного
operation_id не должна выдавать Deluxe повторно. Сопоставляйте фактически
подписанные поля с заказом; не доверяйте неподписанным клиентским значениям.
По документации, проверенной 15.10.2026, используется sign (HMAC-SHA256),
а sha1_hash устарел. Возврат по successURL не является подтверждением.
Серверный обработчик и интеграция с MyEngine в этот статический архив не входят.
