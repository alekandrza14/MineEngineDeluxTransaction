MYENGINE DELUXE — ПЕРЕНОС НА RENDER

Проект: https://github.com/alekandrza14/MineEngineDeluxTransaction
Тип сервиса для текущей версии: Static Site.
Оплата: 10 ₽ через ЮMoney, режим разработчика настроен для ID test.

1. ОБНОВИТЕ ИСХОДНИКИ
Распакуйте архив. Загрузите СОДЕРЖИМОЕ папки myengine-deluxe в корень
репозитория MineEngineDeluxTransaction с заменой предыдущих версий.
В корне должны находиться index.html, config.js, render.yaml,
а скрипт сборки — по пути scripts/build-static.mjs.
Не загружайте ZIP как единственный файл и не создавайте лишнюю вложенную папку.
Ваш настроенный config.js уже включён. Пересоздавать его не нужно.

2. СОЗДАЙТЕ САЙТ В RENDER
Откройте https://dashboard.render.com/ и выберите New → Static Site.
Подключите GitHub и выберите alekandrza14/MineEngineDeluxTransaction.

Name: mineengine-deluxe (если имя занято, выберите другое)
Branch: ветка, в которую вы загрузили эти файлы
Root Directory: оставьте пустым, если index.html и scripts лежат в корне
Build Command: node scripts/build-static.mjs
Publish Directory: dist

При необходимости добавьте переменную окружения SKIP_INSTALL_DEPS=true:
этому проекту не требуются npm install и сторонние зависимости.
Start Command для Static Site не нужен. Web Service для этой версии не нужен.
Нажмите Create Static Site. После успешной публикации используйте HTTPS-адрес,
который выдаст Render. Не угадывайте адрес по имени сервиса.

АЛЬТЕРНАТИВА: BLUEPRINT
В Render выберите New → Blueprint, укажите этот репозиторий и ветку.
Настройки подхватятся из render.yaml. В файле не создаются серверы или базы,
он описывает только один Static Site. Проверьте выбранные ресурсы в Render.
Если у вас уже есть сервис с именем mineengine-deluxe, не применяйте Blueprint
вслепую: Render может сопоставить совпадающее имя с существующим сервисом.
Выберите подходящий существующий Static Site или задайте уникальное имя.

4. УБЕРИТЕ МАГАЗИН С GITHUB PAGES
Когда новый адрес проверен, отключите старую публикацию Pages в настройках
репозитория или оставьте на Pages отдельную информационную страницу проекта.
Сам репозиторий с кодом удалять не нужно. Отключение старой страницы здесь
не выполнено: это действие требуется в вашем аккаунте GitHub.

ЧТО ПУБЛИКУЕТСЯ
Скрипт создаёт dist и копирует только 7 публичных файлов сайта.
Папки tools, scripts, инструкции и render.yaml в опубликованный сайт не входят.
Не редактируйте dist вручную: меняйте исходники, затем запускайте новую сборку.
Локальная проверка сборки: node scripts/build-static.mjs
При настройке через Blueprint публикация обновляется после коммита в выбранную ветку.

ПЕРЕНОС НЕ ДОБАВЛЯЕТ СЕРВЕРНУЮ ПРОВЕРКУ ОПЛАТЫ
Обычная выдача Deluxe остаётся ручной. Сертификат разработчика выдаётся
при локальном совпадении данных. Для автоматических платёжных уведомлений
и подписанных лицензий позднее потребуется отдельный Web Service.
